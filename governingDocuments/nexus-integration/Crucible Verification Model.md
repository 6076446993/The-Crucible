# Crucible Verification Model

Verification applies only to tested properties.

Verification does not imply unrestricted generalization.

Verification requires:

- Evidence
- Provenance
- Scope boundaries
- Controlled testing
- Reproducibility

---

Verification Outcomes

VERIFIED

FAILED

INSUFFICIENT_EVIDENCE

BLOCKED

---

Verification must preserve:

- Inputs
- Outputs
- Test conditions
- Evidence references
