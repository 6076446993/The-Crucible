# Crucible Evidence Classification

Evidence classifications:

INSUFFICIENT_EVIDENCE

REJECTED_EVIDENCE

CRUCIBLE_ISSUE

SUPPORTED

VERIFIED

---

Definitions

INSUFFICIENT_EVIDENCE

Available evidence cannot support the claim.

REJECTED_EVIDENCE

Evidence fails validation.

CRUCIBLE_ISSUE

Verification process encountered an internal issue.

SUPPORTED

Evidence supports the claim but verification remains incomplete.

VERIFIED

Evidence and testing satisfy verification requirements.
