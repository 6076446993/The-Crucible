# Crucible Contract Requirements

## Purpose

This document extracts shared contract requirements derived from Crucible governance.

Crucible functions as the verification authority within Nexus.

---

## Required Contract Objects

EvidenceRecord

ProvenanceRecord

Attestation

VerificationResult

VerificationCheck

FailureRecord

FailureCode

HypothesisPlan

ClaimBoundary

ExperimentBoundary

GeneralizationBoundary

---

## Core Principles

Evidence is not proof.

Verification is not authorization.

Authorization is not scientific proof.

Learning promotion requires evidence-backed verification.

---

## Verification Authority

Crucible is responsible for producing verification outcomes.

Verification results must be evidence-backed.

Verification results must preserve provenance.
